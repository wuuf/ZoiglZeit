Daten auf deinem Gerät

Die Zoigl-Termine sind fest in der App enthalten. Wenn du Zoiglstuben als Favoriten markierst, speichert die App diese Auswahl ausschließlich lokal auf deinem Gerät. Sie wird nicht übertragen und beim Löschen der App entfernt.

Kartenansicht (OpenStreetMap)

Für die Karte lädt die App Kartenkacheln von den Servern der OpenStreetMap Foundation (tile.openstreetmap.org). Dabei wird technisch bedingt deine IP-Adresse an diese Server übermittelt. Die Kacheln werden nur geladen, wenn du eine Karte öffnest. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO; das berechtigte Interesse liegt in der Darstellung der Zoiglorte. Weitere Informationen findest du in der Datenschutzerklärung der OpenStreetMap Foundation.

Externe Links

Wenn du einen Link antippst, etwa zur Homepage einer Zoiglstube, zu GitHub oder eine E-Mail-Adresse, öffnet sich dein Browser bzw. dein E-Mail-Programm. Für die dort verarbeiteten Daten gelten die Bestimmungen des jeweiligen Anbieters.
